# NeckGuardian · 肩颈健康助手

摄像头在旁边看着你的坐姿 —— 头歪了、肩塌了、脖子前倾了，它就知道。
分数低了会提醒你起来活动，长期数据会告诉你哪天坐得最差。

**全部在本机完成，摄像头画面不出你的电脑或手机，也不联网。**

## 🚀 安装

**Windows**：双击安装包 → 一路下一步 → 首次启动时允许摄像头。

**macOS**：打开 `.dmg`，把 NeckGuardian 拖进「应用程序」。
⚠️ 包**没有做 Apple 签名公证**，直接双击会提示"无法验证开发者"或"已损坏"。两种解法：

- 在「应用程序」里 **右键 →「打开」**，弹窗里再点一次「打开」（只需一次）
- 或者执行：`xattr -dr com.apple.quarantine /Applications/NeckGuardian.app`

**Android**：下载 APK → 系统提示时允许"安装未知来源应用" → 安装 → 首次打开允许摄像头。
（从 v1.3.0 起各版本都由同一把密钥签名，可以直接覆盖安装，不用先卸载。）

## 📖 怎么用

### 界面

打开就是主界面：中间是摄像头画面与实时骨架，左上角是环形评分（0–100），
顶部三个小格显示头部侧倾、肩部高差、脊柱倾斜的实时数值。左侧边栏切页面（手机端是底部标签栏）。

### 四个主要功能

**📷 姿势监测** —— 启动后摄像头自动开启，实时检测三项指标并打分：
绿（良好）／黄（一般）／红（需要调整）。桌面端还能最小化到系统托盘继续跑。

**⏰ 智能提醒** —— 默认每 **30 分钟**提醒一次（可在设置里改成 2–120 分钟）。
弹窗里可以选「开始活动」或「稍后提醒」（5 分钟后再来）。

**🧘 肩颈活动** —— 跟着屏幕上的动画做颈部拉伸、肩部环绕、深呼吸。
做完有积分奖励。手机端这一页是整屏固定的，不滚动。

**📊 数据统计** —— 今日评分趋势与活动次数、本周每日对比、历史记录。

### 设置

| 项 | 说明 |
|---|---|
| 提醒间隔 | 2–120 分钟 |
| AI 增强模式 | 接入 DeepSeek 生成分析报告（需自备 API Key，见下） |
| 语音播报 | 提醒时语音念出来 |
| 开机自启动 | 桌面端才有 |
| 原始采样保留期 | 7–365 天，默认 30；超期的逐帧数据会被清理，**每日汇总永久保留** |

### 🗂 数据管理（导出 / 导入 / 清除）

「设置 → 数据管理」里能看到占了多大空间、存了多少条、数据从哪天到哪天。

- **导出备份 (JSON)** —— 一份完整备份，**手机和电脑导出的文件可以互相导入**，
  换设备直接接着用。
- **导出每日汇总 (CSV)** —— 每天一行（日均分、最低分、三项问题占比），
  用 Excel 打开不乱码。
- **导入备份** —— 会**覆盖**当前的健康数据（设置项是合并，不会抹掉你的 API Key）。
- **清除健康数据** —— 只清姿势采样、每日汇总、活动和时长；提醒间隔、AI 配置等设置保留。
  需要点两次确认。

> 为了让数据库不无限膨胀，逐帧的原始采样只保留最近 N 天（默认 30），
> 更早的会被清理 —— 但**每日汇总永久保留**，所以趋势图不会缺口。
> 想留得更久就把「原始采样保留期」调大。
>
> 导出文件里**不包含** DeepSeek API Key。

### 🤖 AI 肩颈分析（可选）

用 DeepSeek 大模型，结合你的实时姿态和近期数据，生成一份结构化报告
（整体评估 → 问题分析 → 改善建议 → 今日行动）。

1. 到 [platform.deepseek.com](https://platform.deepseek.com) 申请一个 API Key
2. 打开「设置 → DeepSeek 大模型」，粘贴 Key，选模型（`deepseek-chat` 快 / `deepseek-reasoner` 深）
3. 点「保存配置」→「测试连接」
4. 开启「AI 增强模式」，回主界面点「生成分析」

> 不配 Key 也能用，只是没有 AI 分析；配了但断网时会自动降级到本地预设建议。

### 快捷键（桌面端）

`Ctrl +` 放大 ｜ `Ctrl -` 缩小 ｜ `Ctrl 0` 恢复默认。手机端没有快捷键。

### 手机端和电脑端有什么不一样

| | 电脑端 | 手机端 |
|---|---|---|
| 怎么算的 | 本机 Python 后端 | **手机自己算**，不需要后端 |
| 摄像头画面 | 传给本机后端处理 | **完全不出手机** |
| 数据存哪 | 本机 SQLite 文件 | 应用内存储（**卸载即清除**） |
| AI 分析 | 支持 | 不提供 |
| 开机自启 | 支持 | 不提供 |

> 手机端**切到后台或锁屏后会暂停**检测与提醒 —— 这是手机系统冻结后台网页的机制，不是 bug。

## 🔒 隐私

| | |
|---|---|
| **摄像头画面** | 只在本机处理，**不上传、不保存**。手机端连设备都不出 |
| **姿态数据** | 桌面的存在本机 SQLite，手机的存在应用内存储。不上云 |
| **导出备份** | 由你主动触发，文件存到你自己选的位置。文件里**不含 API Key** |
| **AI 分析** | 只有你主动点「生成分析」时，才把**匿名的三个角度数值 + 统计数字**发给 DeepSeek，**不含画面** |
| **API Key** | 只存在本机数据库，界面上永远显示为掩码；导入备份也不会覆盖它 |
| **后端服务** | 只监听 `127.0.0.1`，局域网内其他设备也访问不到 |

## ❓ 常见问题

**摄像头打不开？**
先看系统权限：Windows「设置 → 隐私 → 相机」；macOS「系统设置 → 隐私与安全性 → 摄像头」；
Android「设置 → 应用 → NeckGuardian → 权限 → 相机」；iOS「设置 → NeckGuardian → 相机」。
改完权限要**重启应用**。

**为什么我的分数总是从 100 直接掉到 78 附近，见不到 85 分？**
这是设计如此。提醒和分数是严格绑定的：**只要出现提醒，分数就一定低于 80**。
所以 79–89 这个区间永远不会出现。分数要么 ≥90（没问题），要么 ≤78（有提醒）。
另外分档边界处会有**跳变**（比如头部侧倾从 5.00° 到 5.01°，分数从 94 掉到 78），
这也是"有提醒就必须扣够分"的必然结果，不是算错了。

**手机端分数和电脑端对不上？**
不会。四端的角度、平滑、评分三套逻辑是逐位等价的，有自动对拍守着。
真发现不一致请提 Issue。

**提醒不来了？**
桌面端确认应用还在托盘里（别被系统休眠）；手机端**必须保持 App 在前台**，切后台会被系统暂停计时。

**换手机 / 换电脑，数据能带走吗？**
能。「设置 → 数据管理 → 导出备份」会存出一份 JSON 文件，在新设备上「导入备份」即可，
手机和电脑导出的文件可以互相导入。**导出的文件里不含你的 API Key**（那属于凭据）。

**手机端卸载了数据还在吗？**
不在。卸载会连同应用内存储一起清掉 —— 所以**换设备或重装前先导出一份备份**。

**为什么数据里少了很久以前的逐帧记录？**
原始采样只保留最近 N 天（默认 30，可调到 365），更早的会被自动清理，防止数据库无限膨胀。
**每日汇总永久保留**，所以趋势图和周报不会有缺口。

**升级后统计图表里有一段落差？**
v1.3.6 调整过评分公式，旧版本记录的分数是按旧公式算的，跨版本交界处会有落差。
这是预期内的，不是数据出错。

**怎么退出？**
桌面端：右键托盘图标 →「退出」，或在设置页点「退出应用」。
手机端：从最近任务列表划掉，或系统设置里强制停止。
